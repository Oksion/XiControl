# Xiaomi PC Manager OSD resources

This directory is populated from the locally installed Xiaomi PC Manager 5.8.1.121 by
`tools/extract-xiaomi-osd-assets.ps1`.

Source: `C:\Program Files\MI\XiaomiPCManager\5.8.1.121\res\Image\`

The files retain their original names so `OemOsdAssets` can reproduce the OEM selection rules
for light/dark themes, English-labelled variants and Windows DPI scales from 100% through 500%.
They are third-party Xiaomi artwork; preserve this provenance when redistributing a build.
