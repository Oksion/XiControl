# Локальные ресурсы Xiaomi OSD

XiControl не хранит и не распространяет PNG из Xiaomi PC Manager: это стороннее оформление,
для которого нет разрешения на распространение под GPLv3. Каталог `osd/` создаётся только
локально и игнорируется git.

Если Xiaomi PC Manager установлен вместе с ресурсами OSD, извлеките их командой:

```powershell
.\tools\extract-xiaomi-osd-assets.ps1
```

Если автообнаружение не нашло каталог нужной версии, укажите его явно:

```powershell
.\tools\extract-xiaomi-osd-assets.ps1 `
  -SourceRoot 'C:\Program Files\MI\XiaomiPCManager\5.8.1.121\res\Image'
```

После этого обычная локальная сборка встраивает найденные PNG как `oem.osd.*.png`.
Селектор `OemOsdAssets` выбирает доступный Light/Dark, английский и ближайший DPI-вариант.
Если набора или нужного семейства нет, его `TryLoad`/`TryOpen` возвращают `false`: вызывающий
обязан оставить стандартный локализованный `OsdForm`. Официальные сборки работают именно так.

Не добавляйте извлечённые PNG в коммиты и не распространяйте собранный с ними бинарник без
отдельного разрешения правообладателя.
