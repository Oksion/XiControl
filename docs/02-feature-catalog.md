# Каталог функций — что можно положить в приложение

> 📌 **Исторический документ этапа планирования.** Актуальный статус — в
> [ROADMAP.md](../ROADMAP.md); ниже по строкам проставлены пометки «как вышло».

Легенда источника:
- 🟢 **WMI-native** — уникальная ценность, идёт через MIFS-прошивку.
- 🔵 **HW-event** — приходит WMI-событием (`HID_EVENT20`), нужен резидентный слушатель.
- ⚪ **Win32-generic** — стандартный Windows, к прошивке не относится, «бесплатно».

Оценка: **Core** — ядро продукта; **Nice** — приятное дополнение; **Later** — потом/по желанию; **Skip** — не тащить.

## Ядро (обязательно)

| Фича | Тип | cmd | Оценка | Комментарий |
|------|-----|-----|--------|-------------|
| Режим производительности | 🟢 | `0x08` | **Core** | Тихий / Турбо / Full-speed / Auto(Smart). Full-speed — только от сети. Auto только на `TM24*`. |
| Порог заряда 40–80/100% | 🟢 | `0x10` | **Core** | Многоуровневый (переоткрыто, см. `12-charge-levels.md`): на TM2424 40/50/60/70/80/100%, прошивка сама валидирует набор. Перед вкл — выкл (сброс EC). |
| Индикация в трее + меню | — | — | **Core** | Текущий режим/лимит, быстрое переключение. |
| OSD при переключении | — | — | **Core** | Как в CoreCharge — красиво и понятно (можно взять идею, не код). |
| Автозапуск при логине | — | — | **Core** ✅ | Task Scheduler, `/rl highest` — admin нужен и для GET, и для SET (проверено). Задача своя на каждого пользователя (SID в имени), самопочинка пути и версии на старте. |

## Приятные дополнения

| Фича | Тип | cmd | Оценка | Комментарий |
|------|-----|-----|--------|-------------|
| Телеметрия: обороты вентиляторов | 🟢 | `0x0D` | ~~Nice~~ ❌ | На TM2424 `0xE0` — функции нет (проверено свипом). |
| Телеметрия: температура CPU | 🟢/⚪ | `0x16`→DPTF | ~~❌~~ ✅ **сделано** | MIFS `0x16`=`0xE0` бесполезен, **но Intel DPTF** (WMI `root\wmi\EsifDeviceInformation`, `.Temperature` °C, максимум активных доменов) отдаёт живые температуры driver-free — строка-график в «Мониторе». Тема была закрыта как «невозможно» → переоткрыта ([09](09-power-monitoring.md)). На машинах **без Intel** (AMD-модели) провайдера DPTF нет — там читается ACPI-термозона `MSAcpi_ThermalZoneTemperature`. Это другая величина: одно грубое число платы, и подписана она в UI как «Температура платы». Смысл зоны зависит от вендора — на TM2424 она отдаёт заглушку 27,9 °C при 73 °C на доменах DPTF, на TM2113 — правдоподобные 49,1 °C (XIC-41). Per-core/PCH через MSR по-прежнему не берём. |
| Мощность адаптера (ADPW) + здоровье (SOH1) | 🟢 | `0x10`/`06`,`01` | ✅ **сделано** | `arg 0x06` — номинал PD-блока в Вт (0=не PD): ватты в OSD/Мониторе + бейдж «слабый/не-PD». `arg 0x01` — SOH1 %, панель износа батареи. Найдено свипом cmd `0x10`. |
| Тип БП (USB-C / DC) | 🟢 | `0x13` | ~~Nice~~ ❌ | На TM2424 `0xE0`. |
| Яркость подсветки клавиатуры | 🟢 | `0x12` | ~~Nice~~ ❌ | Через WMI нет (`0xE0`); уровень приходит **событием** `0x05` → сделан OSD. |
| Реакция на Fn-клавиши (OSD) | 🔵 | event | ✅ сделано | OSD: подсветка (4 уровня), микрофон, Fn-Lock, режимы. |
| Mi / AI кнопка → своё действие | 🔵 | event | ✅ сделано | Mi: клик/двойной/удержание (настраивается); AI: Copilot или своя программа. |
| Синхронизация mic-mute со звуком Windows | 🔵/⚪ | `0x0A`+audio | ✅ сделано | Core Audio mute + OSD по событию `0x21`. |
| Скрытый режим Эко | 🟢 | `0x08`=`0x0A` | ✅ сделано | Найден позже по EC-референсу, в каталоге не значился. |

## Позже / по желанию

| Фича | Тип | Оценка | Комментарий |
|------|-----|--------|-------------|
| Режим GPU (Hybrid/Discrete/UMA) | 🟢 `0x09` | **Later** | Мощно, но рискованно: обычно требует перелогина/перезагрузки, легко «уронить» вывод. Только после тестов. |
| Переключение частоты обновления | ⚪ | **Done (v0.7.0)** | Авто-герцовка по питанию: 120 Гц от сети / 60 Гц от батареи. `ChangeDisplaySettingsEx` по **встроенной панели** (ищется через CCD — с `null` правился бы основной экран, XIC-21); опция «Удерживать частоту» возвращает её после чужих изменений (XIC-22). Аппаратная клавиша герцовки (`0x1A`, алиас `0x13`) перебирает режимы встроенной панели и показывает фактическую частоту в OSD; при включённом удержании осознанное нажатие становится значением профиля текущего питания — иначе сторож откатил бы его через 1,5 с. На моделях без такой клавиши тот же цикл вешается на любую другую действием `hz` (XIC-54, XIC-58). |
| Вкл/выкл тачпада и сенсорного экрана | ⚪ | **Done (v0.7.0)** | Действие для любой клавиши + ячейка в панели + OSD. SetupAPI/CfgMgr32: отключается родительский HID-узел (общий `HidNodeToggle`; тачпад `U:0005`, тачскрин `U:0004`). Без PERSIST — по умолчанию после ребута снова включены; с «Помнить выключенным» (XIC-53) приложение гасит вернувшееся устройство на старте снова (XIC-79). Плюс мёртвая зона у нижнего края (XIC-24). |
| Индикатор-метрика в трее | ⚪ | **Done (v0.12.0)** | Второй `NotifyIcon` с цифрой: Вт (Battery API) / CPU (`GetSystemTimes`) / GPU (IGCL) / NPU (PDH `GPU Engine`, только если NPU есть — XIC-86, v0.17.0) / RAM / °C (DPTF) — источники общие с «Монитором». Текст рендерится в саму иконку (PNG-ICO в памяти, без GDI-хэндлов); опция выключена (дефолт) = не создаётся ничего, ноль нагрузки (XIC-35). |
| ICC цветовые профили | ⚪ | **Skip** | Нишевое, не про эту утилиту. |
| Произвольный % заряда (1–100) | ❌ EC | **Skip** | Осознанно отказались: требует WinRing0. Через WMI невозможно. |

## Мэппинг режимов — как вышло

Планировали 3 упрощённые кнопки, по факту показываем **все 5 режимов прошивки**
(Эко/Тихий/Авто/Турбо/Полная), а упрощение отдали пользователю: Эко и Полную
мощность можно скрыть в Настройках. Позже видимость разрезали по источнику питания
(`HiddenModesBySource`: свой набор для сети и для батареи, XIC-65), а режим, который прошивка
отвергла у обоих источников, убирается из списка сам (XIC-44).

## Итоговый MVP — план vs факт

- **v0.1 (план) = v0.1 (факт):** трей + меню + OSD; режимы + заряд; автозапуск. ✅
- **v0.2 (план — телеметрия): не состоялся** — телеметрии на TM2424 нет (`0xE0`).
  Вместо неё v0.2–v0.5: SVG-иконки, анимации, жесты Mi, ремапы, Эко, Fn-Lock, китайский.
- **v0.3 (план — события): сделан раньше срока** и без службы — событий из admin-сессии
  оказалось достаточно (см. `03-architecture.md`).

## Чего в каталоге не было вовсе

Большая часть нынешнего приложения в план не входила — появилась по ходу, когда нашлись
driver-free каналы или пришли запросы тестеров. Полный список — [ROADMAP.md](../ROADMAP.md)
«Сделано», по версиям — [CHANGELOG.md](../CHANGELOG.md). Самое заметное:

- виджет «Монитор» — ватты, CPU, температуры (DPTF), iGPU (IGCL), NPU, RAM ([09](09-power-monitoring.md));
- запоминание и лимит яркости по питанию, авто-яркость по датчику с обучаемой кривой ([13](13-auto-brightness.md));
- «режим совы», «В дорогу» (разовый заряд до 100 %), программный порог для моделей без аппаратного;
- тачпад: мёртвая зона, сила вибрации и усилие нажатия, краевые ползунки, сильное нажатие как действие;
- окно настроек в стиле Win11, три языка, портативный режим;
- HTTP API и вебхук для Home Assistant ([15](15-http-api.md));
- проверка драйверов и BIOS у Xiaomi, управление службами Xiaomi ([16](16-oem-driver-check.md), [17](17-oem-services.md)).
